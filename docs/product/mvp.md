# Trama MVP

## Product statement

Trama is a contextual life-management system. It helps the user investigate
complex situations, conduct goals, and keep actions, risks, deadlines, and open
loops actively maintained.

## First proof

The first vertical slice proves that Trama can:

1. create a Plot with a goal and central question;
2. turn an unresolved concern into an actionable commitment;
3. own the operational status, effective priority, and next review date;
4. require a structured outcome rather than a bare `done` flag;
5. reevaluate consequences after every meaningful update;
6. preserve a complete audit trail.
7. run a proactive operational review that detects time-driven priority changes
   and items requiring attention.

## Non-goals for the first slice

- running an LLM;
- MCP or provider-specific adapters;
- external calendar synchronization and notification delivery;
- the full investigative graph;
- automatic semantic conclusions.

These capabilities must connect through stable application contracts without
changing the domain model.
